    Dynamic Skip Links

    Press Tab to reveal a list of skip links generated from this page's landmarks and headings.

    What are skip links?

    A skip link is a visually hidden anchor that appears when focused. It lets keyboard and assistive-technology users bypass repeated content — like the header or navigation — and jump directly to the section they need.

    Most implementations provide a single "Skip to main content" link. This module makes them dynamic: it scans the page for landmarks and headings and builds the full list automatically.

    How to integrate

    Step 1 — Include the module files

    Copy dynamic-skip-links.js and dynamic-skip-links.css into your project. These are the only two files the module requires.

    <link rel="stylesheet" href="dynamic-skip-links.css">

<!-- before </body> -->
<script src="dynamic-skip-links.js"></script>

    Step 2 — Add the HTML snippet

    Place this as the first element inside <body>:

    <nav id="skiplinks" aria-label="Skip links">
  <ul id="js-nav-skip-links"></ul>
</nav>

    Step 3 — Style the revealed links

    dynamic-skip-links.css handles hiding and revealing the links mechanically but applies no visual design. Add this to your own stylesheet and adjust to match your project:

    #skiplinks a:focus-visible,
#skiplinks a:active {
  padding: .5rem 1rem;
  background-color: #fff;
  border: 2px solid #000;
  text-align: center;
  text-decoration: none;
}

    That is the entire integration. No other changes to your HTML or CSS are needed.

    Configuration

    Two values at the top of dynamic-skip-links.js can be changed if the default IDs conflict with your project:

    var config = {
  // id of the <ul> that receives the generated links
  containerId: "js-nav-skip-links",

  // elements that become skip link targets
  selector: "header, main, nav, form, h1, h2"
};

    One CSS custom property is also available if you need to adjust the stacking order:

    :root {
  --skiplinks-z-index: 9999; /* default */
}

    Label resolution

    Each skip link label is resolved in this order:

    1. aria-label on the element
    2. Text of the element referenced by aria-labelledby
    3. The element's own text content (headings only)
    4. Fallback: No label

    Labels longer than 60 characters are trimmed automatically.
