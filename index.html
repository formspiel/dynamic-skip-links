    Dynamic Skip Links

    Press Tab to reveal a list of skip links generated from this page's landmarks and headings.

    What are skip links?

    A skip link is a visually hidden anchor that appears when focused. It lets keyboard and assistive-technology users bypass repeated content — like the header or navigation — and jump directly to the section they need.

    Most implementations provide a single "Skip to main content" link. This library makes them dynamic: it scans the page for landmarks and headings and builds the full list automatically.

    How to use it

    Add the skip links container before any other content and include the script. Everything else is automatic.

    <nav id="skiplinks" aria-label="Skip links">
  <ul id="js-nav-skip-links"></ul>
</nav>

<!-- your page content -->

<script src="behaviour.js"></script>

    Label resolution

    Each skip link label is resolved in this order:

    1. aria-label on the element
    2. The text of the element referenced by aria-labelledby
    3. The element's own text content (headings only)
    4. Fallback: No label

    Labels longer than 60 characters are trimmed automatically.

    Accessibility notes

    Target elements receive tabindex="-1" so keyboard focus lands correctly when a skip link is activated. The skip links navigation uses aria-label="Skip links" to identify itself as a distinct landmark to screen readers.
